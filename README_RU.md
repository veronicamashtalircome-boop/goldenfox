# Golden Fox Sports Academy — сайт для GitHub Pages

Это готовый адаптивный сайт на HTML, CSS и JavaScript. Конструктор не нужен.

## Что внутри
- `index.html` — страницы, тексты, карточки и формы
- `styles.css` — оформление, цвета, мобильная версия
- `script.js` — мобильное меню, окно заявки и подготовка письма
- `config.js` — контактный адрес Golden Fox (ВАЖНО заполнить)
- `assets/` — логотип и временные иллюстрации

## Как запустить через GitHub
1. Войдите в github.com и создайте **Public** репозиторий, например `golden-fox-website`.
2. Нажмите **Add file → Upload files**. Загрузите файлы `index.html`, `styles.css`, `script.js`, `config.js` и **папку `assets` с изображениями**, сохранив пути.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**.
5. В **Build and deployment** установите **Deploy from a branch**, выберите `main` и `/ (root)`, нажмите **Save**.
6. Сайт будет опубликован по адресу вида `https://ВАШ-ЛОГИН.github.io/golden-fox-website/`. GitHub покажет фактический URL в Settings → Pages.

## До публичного запуска ОБЯЗАТЕЛЬНО
- В `config.js` вписать реальный рабочий email вместо пустой строки. Без него форма открывается, но не отправляет письмо. Форма использует mailto: посетитель должен подтвердить отправку в своём почтовом приложении. Это **не серверная онлайн-запись**.
- Заменить демонстрационные ИИ-фотографии реальными (и получить необходимые согласия, если на фото узнаваемы дети). Нельзя представлять ИИ-фото как документальные фото тренировок.
- Проверить все тексты, программы, возрастные ограничения, цены и расписание.
- Добавить юридически корректные страницы `Impressum`, `Datenschutzerklärung` и при необходимости условия/AGB, прежде чем использовать сайт для реального бизнеса. Сейчас они намеренно не созданы: для них нужны точные данные и условия.
- Проверить правовой и страховой статус перед продажей занятий. Особенно если получаете AMS.

## Как заменить изображения
В папку `assets` загрузите ваши фото, сохраняя имена файлов `hero-skater.jpg`, `kids-beginner.jpg`, `kids-advanced.jpg`, `skates-closeup.jpg`. Если имена другие — обновите ссылки в HTML/CSS.

## Как изменить оранжевый цвет
В начале `styles.css` измените значение `--orange:#ff9918`.

## Важное ограничение
GitHub Pages — статический хостинг. Для онлайн-оплат, подтверждений с ограничением мест, личных кабинетов и безопасного хранения данных потребуется отдельный сервис бронирования или backend. Никогда не публикуйте персональные данные учеников в публичном репозитории.

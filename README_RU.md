# Golden Fox V3 — многостраничный сайт с новой главной

Страницы: index.html (новая главная), trainings.html, levels.html, events.html (новая!), termine.html, standorte.html, about.html, partner.html, faq.html, anfrage.html.

## Как обновить на GitHub Pages
1. Скачай ZIP и распакуй его на компьютере.
2. Открой GitHub → репозиторий goldenfox → Add file → Upload files.
3. Выдели **все файлы внутри** распакованной папки и перетащи в GitHub. Не загружай ZIP вместо файлов.
4. Замени существующие файлы, нажми Commit changes.
5. После обновления сайта нажми Ctrl+F5. Главная должна показать крупное название Golden Fox, 5 Level, Events & Cup.
